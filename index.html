Dit is een lijst van veelvoorkomende commandos in de terminal..:

  • Commando 1: pwd

    Print working directory

  • Commando 2: ls

    Geeft een lijst van de bestanden en mappen in de huidige map

  • Commando 3: cd

    Change directory

  • Commando 4: man

    Toon de handleiding van een commando

  • Commando 5: tree

    Toon de mapstructuur in een boomstructuur

  • Commando 6: cp

    Kopieer bestanden of mappen

  • Commando 7: mv

    Verplaats bestanden of mappen

  • Commando 8: rm

    Verwijder bestanden of mappen

  • Commando 9: cat

    Toon de inhoud van een bestand

  • Commando 10: less

    Toon de inhoud van een bestand pagina voor pagina

  • Commando 11: nano

    Een eenvoudige tekstbewerker

  • Commando 12: head

    Toon het eerste gedeelte van een bestand

  • Commando 13: tail

    Toon het laatste gedeelte van een bestand

  • Commando 14: touch

    Maak een leeg bestand aan

  • Commando 15: mkdir

    Maak een nieuwe map aan

  • Commando 16: sudo

    Voer een commando uit als administrator
